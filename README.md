# Brain Cancer Segmentation Notebook

## Overview

This repository contains a Jupyter notebook **`Brain_cancer_segmentation.ipynb`** that demonstrates a complete workflow for brain tumor segmentation using the BraTS2020 dataset. The notebook walks through:

1. **Data loading & exploration** – Locate and inspect the MRI modalities (`FLAIR`, `T1`, `T1CE`, `T2`) and segmentation masks.
2. **Pre‑processing** – Resize volumes, normalize intensities, and optionally perform data augmentation.
3. **Model definition** – Build a U‑Net‑style segmentation network with the **`segmentation_models`** library (ResNet34 backbone, TensorFlow‑Keras backend).
4. **Training** – Split data into train/validation sets, configure callbacks, and monitor performance.
5. **Evaluation** – Compute metrics such as Dice coefficient, Jaccard index, and F1‑score on a hold‑out set.
6. **Visualization** – Plot sample slices with ground‑truth and predicted masks.

The notebook is fully executable in a standard Python environment with TensorFlow 2.x and the `segmentation_models` package.

## Prerequisites

- Python 3.8+ (tested on 3.10)
- Packages (install via `pip`):
  ```bash
  pip install numpy nibabel matplotlib pandas scikit-learn tensorflow==2.10.1 segmentation_models
  ```
- The **BraTS2020** training data should be placed under the folder `BraTS2020_TrainingData/MICCAI_BraTS2020_TrainingData` relative to the notebook location.

## Notes & Tips

- The notebook uses a fixed random seed for reproducibility (`SEED = 42`).
- GPU acceleration is automatically detected via `tf.config.list_physical_devices('GPU')`. If no GPU is available, training will fall back to CPU (significantly slower).
- To experiment with different backbones, modify `BACKBONE` and optionally install the required pretrained weights.
- The `segmentation_models` library expects the input shape `(IMG_SIZE, IMG_SIZE, CHANNELS)`. Ensure that the pre‑processing step matches this expectation.
- The notebook includes extensive `print` statements for progress tracking and debugging.
